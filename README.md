# Sorting Visualizer

A dynamic visual representation of popular sorting algorithms built using **HTML, CSS, and JavaScript**.

## 🚀 Features
- Adjustable array size
- Adjustable sorting speed
- Individual visualization for each algorithm
- Real-time bar updates
- Clean UI and responsive design

## 📌 Algorithms Implemented
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Heap Sort

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (ES6)
